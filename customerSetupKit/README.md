# NTZ Bid Copilot Customer Setup Kit

This folder contains a simple bid-agent setup package that can be published as release assets or shared with customers.

## Files

- Customer-Setup-Guide.docx
- sample-master-qna.xlsx
- sample-capability-statement.docx
- sample-security-whitepaper.docx
- IT-Admin-Runbook.docx

## Suggested use

1. Upload these assets to a SharePoint site or public release location.
2. Replace the placeholder content with customer-specific templates and policies.
3. Link the published files from the declarative agent instructions.
